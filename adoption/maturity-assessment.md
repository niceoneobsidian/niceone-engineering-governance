# NUEGS Maturity Assessment

| Level | Meaning | Minimum evidence |
|---|---|---|
| M0 — Unknown | State/owner unknown | Audit opened |
| M1 — Defined | Scope, owner, risk and verification method recorded | Reviewed control |
| M2 — Implemented | Mechanism exists at a named enforcement point | Implementation reference |
| M3 — Tested | Defined checks exercised | Dated output and revision |
| M4 — Verified | Evidence meets acceptance criteria for stated scope | Reviewed evidence record |
| M5 — Adopted | Owner accepts ongoing control and review | Adoption record and review date |

Assess each control separately. Documentation alone does not prove implementation. Record blocked, failed and not-assessed separately. Evidence should identify target, revision, method, result, date and limitations. OIS capability maturity remains a separate lifecycle.
