# Authority Hierarchy

Apply the highest applicable authority first: (1) law/regulation/contracts/mandatory security duties; (2) approved project constraints; (3) approved architecture decisions and interface contracts; (4) mandatory NUEGS controls and selected profile; (5) repository standards; (6) recommendations; (7) personal preferences.

When sources conflict: pause risky work, capture exact sources and statements, assess scope and reversibility, ask the accountable owner, record the decision, and add a regression check if practical. Do not silently follow lower-priority instructions. Natural-language prompts and model outputs never grant permissions.
