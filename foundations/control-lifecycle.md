# Control Lifecycle

NUEGS lifecycle: `Proposed → Defined → Implemented → Tested → Verified → Adopted`.

- Proposed: under discussion; not an adopted requirement.
- Defined: scope, owner, risk, requirement, implementation point and verification method recorded.
- Implemented: mechanism exists at the stated location.
- Tested: defined checks ran and results are recorded.
- Verified: reviewed evidence meets acceptance criteria for a stated revision/environment.
- Adopted: accountable owner accepts the control and ongoing review duty.

Controls may be deprecated or superseded with a reason and replacement reference. OIS capability maturity is separate: `UNKNOWN → DESIGNED → IMPLEMENTED → TESTED → INTEGRATED → DEPLOYED → ACTIVATED → PRODUCTION VERIFIED`.
